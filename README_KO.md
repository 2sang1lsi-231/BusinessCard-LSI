# 명함관리 LSI v1.2

안드로이드용 로컬 명함관리 앱입니다. 기존 CamCard 데이터를 그대로 활용하면서 새 명함은 촬영/사진 선택 후 한국어 OCR로 자동 입력할 수 있도록 구성했습니다.

## v1.2 주요 기능
- CamCard `Excel + 명함 사진 ZIP` 일괄 가져오기
- CamCard Excel만 가져오기
- 이름/회사/부서/직위/전화/이메일/주소/그룹/메모 통합 검색
- 즐겨찾기 및 그룹 필터
- 명함 앞/뒤 및 추가 앞/뒤 사진 보관/표시
- 신규 명함 직접 등록 및 수정
- 명함 **촬영 → 한국어 OCR → 빈 항목 자동 입력**
- 갤러리 사진 **선택 → 한국어 OCR → 빈 항목 자동 입력**
- OCR 원문 확인 및 저장 전 수동 수정
- 전화, 이메일, 지도, 웹사이트 바로 열기
- 연락처 앱에 명함 정보 저장
- 명함 정보 텍스트 공유
- 항목 길게 누르기 클립보드 복사
- 중복 명함 감지 및 병합
- 전체 데이터 + 사진 ZIP 백업/복원
- 사용하지 않는 명함 사진 정리
- Android 6.0(API 23) 이상 지원

## OCR 방식
- Google ML Kit의 한국어 텍스트 인식 모듈을 앱에 포함합니다.
- OCR 처리는 기기에서 수행되도록 구성되어 명함 사진을 별도 서버로 업로드하지 않습니다.
- 자동 인식 결과는 바로 확정하지 않고 편집 화면의 **빈 항목만 채우며**, 사용자가 저장 전에 확인/수정할 수 있습니다.

## CamCard 호환 검증
사용자가 제공한 실제 CamCard 내보내기 형식으로 검증했습니다.
- Excel: 7개 명함 / 41개 열 인식
- 사진 ZIP: 9개 이미지
- Excel의 사진 파일명과 ZIP 사진 연결: 9/9
- 서로 다른 7개 명함의 동일 전화번호가 잘못 중복 처리되지 않도록 중복 판정 개선

## 데이터 저장
명함 정보는 앱 내부 SQLite DB에, 명함 사진은 앱 전용 내부 저장소에 저장합니다. 전체 백업 기능으로 DB의 명함 정보와 사진을 하나의 ZIP으로 내보낼 수 있습니다.

## 빌드
프로젝트에 `.github/workflows/android-apk.yml`을 포함했습니다. GitHub Actions에서 JDK 17 + Gradle 8.9로 `assembleDebug`를 실행해 설치 가능한 `BusinessCard_LSI_v1.2.apk`를 생성하도록 구성되어 있습니다.
